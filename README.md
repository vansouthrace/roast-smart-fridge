A one-line roast of a smart home gadget, written for the make.fun bounty
[Roast the Smart Fridge: One Line, Best Laugh Wins](https://make.fun/bounty/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9).

The line: a robot vacuum that maps the whole house in an afternoon, then
spends three days stuck under the same couch.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

The program writes the roast to `entry.txt` in the output directory
(1–160 characters, a single line).
